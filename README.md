# Hipófise em Foco — versão 1.0.4

Aplicativo web educativo estático sobre a hipófise, tumores hipofisários, exames, tratamentos e acolhimento ao paciente.

## Publicação no GitHub Pages

O arquivo principal é `index.html`. Para publicar, substitua o arquivo na raiz do repositório configurado no GitHub Pages e confirme a alteração na branch publicada. Depois, abra o site em janela anônima ou atualize sem cache para conferir a versão.

## Alterações técnicas da versão 1.0.4

- Atualização da identificação de versão e data editorial/técnica para 27/11/2026.
- Ajuste da identificação da aplicação nos metadados.
- Identificação acessível da região dinâmica de conteúdo.
- Remoção de regra CSS duplicada.
- Verificação sintática dos quatro blocos JavaScript: sem erros de sintaxe.
- Verificação estrutural: sem IDs HTML duplicados, botões sem tipo ou imagens sem texto alternativo.

## Limites e pendências obrigatórias

- O conteúdo é educativo; não diagnostica, interpreta exames individuais nem prescreve tratamentos.
- A validação clínica independente por endocrinologista, neurocirurgião e oftalmologista/neuro-oftalmologista permanece pendente.
- As referências bibliográficas e seus links devem ser conferidos por um revisor clínico/editorial antes de divulgação institucional.
- A declaração de privacidade descreve o comportamento do código atual; deve ser reavaliada se forem adicionados analytics, formulários, cadastro, comunidade, envio de exames ou serviços externos.
- Esta versão não inclui backend, autenticação, armazenamento de dados de pacientes ou integração com IA.

## Auditoria realizada

A revisão foi estática, baseada nos arquivos entregues. Foram examinados a estrutura HTML, os quatro blocos JavaScript, os identificadores, botões, imagens, links externos, renderização de conteúdo e avisos de segurança clínica. Não foi realizada validação clínica nem teste em todos os navegadores/dispositivos.
